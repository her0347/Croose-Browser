# Croose-Browser
A browser utilising WebView2.

# Due to the release of Breathe Browser, Croose will be marked as archived. Therefore I have stoppped working on it and there will be no more builds/updates. Any issues or pull requests will be closed as well. The official website will also be taken down. You can continue to use the browser, but I cannot guarantee compatibility with other packages or stability. Croose will be archived on 25th July 2026. However the website will be taken down on the 18th July 2026. 

I made this a while ago to familiarise myself with the .NET framework, so it's not amazing, but it works. It uses Chromium to display web pages and TabControl for tabs. Still some stuff not added yet, like tab names changing based on the webpage displayed. Feel free to use as a base for other browsers.

If you are using a legacy version of Windows (e.g. Windows 7), you will need to use this authorised port: https://github.com/isabellewastaken/Croose-Browser-Legacy as WebView will not be compatible with these OS versions. Also note this may not work and I will be of no help if you require it. This is a seperate repo and I am not involved with updates or otherwise expanding development. This means that the modern and legacy browsers will function differently and I can provide no guidance on using the legacy version.
